# Privacy

Live site: https://baditaflorin.github.io/reaction-diffusion-patternmaker/

The app ships with no analytics.

What stays local:

- simulation parameters
- selected preset
- UI settings
- generated texture exports before download

What may be requested from third parties:

- GitHub public commit metadata from https://api.github.com/repos/baditaflorin/reaction-diffusion-patternmaker/commits/main
- PayPal only when the user opens https://www.paypal.com/paypalme/florinbadita

No API keys, accounts, tracking cookies, or project-owned telemetry endpoints are used in v1.
